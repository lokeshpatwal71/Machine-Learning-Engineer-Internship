A beginner-friendly, ten-assignment project that covers the foundations of Data Science: Python, data structures, functions, NumPy, pandas, statistics, data cleaning, exploratory data analysis, visualization, and best practices with a final mini project.

Every assignment is a separate Jupyter notebook that follows the same 12-part format: number/title, aim, objectives, theory, software, dataset, procedure, complete code, expected output, output explanation, observations, and result/conclusion. The numbers quoted in the explanation text are computed by the notebook code, not typed in by hand.

## Datasets and sources

| Dataset | Source | Notes |
|---|---|---|
| **Iris** | R. A. Fisher (1936); UCI Machine Learning Repository https://archive.ics.uci.edu/dataset/53/iris | 150 flowers, 3 species. Loaded through scikit-learn. |
| **Wine** | Forina, M. et al. (1991), PARVUS; UCI https://archive.ics.uci.edu/dataset/109/wine | 178 wines, 13 chemical measurements, 3 cultivars. Loaded through scikit-learn. Please check the UCI page for the current licence terms before reusing the data. |
| **Stocks.csv** | Monthly prices from Yahoo Finance (https://finance.yahoo.com), as stated in the file header | Ships inside Matplotlib's sample data, so no download is needed. Contains real missing values. |
| **Messy students** | **Synthetic.** Generated by code in Assignment 7 (seed 42) | Problems are injected on purpose so the cleaning can be checked against the truth. No real person is represented. |

All datasets load offline from installed libraries, so the notebooks also work on Google Colab without uploading files. Copies are saved in `data/raw/`.

## Results at a glance (all computed by the notebooks)

* **Iris:** mean petal length rises from 1.46 cm (setosa) to 4.26 cm (versicolor) and 5.55 cm (virginica). Petal length and width correlate at r = 0.96 overall but only 0.32–0.79 inside each species.
* **Cleaning:** the synthetic table went from 85 rows (5 duplicates, 8 missing cells, impossible values) to 80 consistent rows; all checks against the injected problems passed.
* **Wine mini project:** all 13 chemical features differ between the three cultivars after a Bonferroni correction (threshold 0.05/13), but the effect sizes range from 0.12 to 0.73; flavanoids, proline and the OD280/OD315 ratio separate the cultivars best.

## What was verified, and what was not

* All ten notebooks were executed top to bottom with a small custom Python runner; the saved outputs, tables and charts come from that real execution and every notebook ends with `assert` validation checks that passed.
* The 19 tests in `tests/` passed with a small stand-in test runner, because `pytest` could not be installed in the build environment. **Please run `python -m pytest` once on your own computer** to confirm with the real tool.
* The notebooks were not opened in Jupyter or Colab during the build. Library versions used for the build are listed in `requirements.txt`; other versions may print slightly different formatting or warnings.
* Timing results in Assignment 4 (loop versus NumPy) depend on the computer and will differ when you re-run it.

## Limitations

* Iris and Wine are small, clean teaching datasets. Findings describe these samples only and do not prove cause and effect.
* Assignment 7 uses synthetic data, not real field data.
* The mini project reports statistical association and effect sizes; it does not build or validate a prediction model.
